GIST system comparison at a common 4 GiB process RAM budget. Ours and DiskANN use beam 4; Glass-NSG and SymphonyQG disk ports use their native beam 1. The QPS axis is logarithmic. Each marker represents one measured test operating point (800 queries, 32 workers). Lines connect widths 10, 20, 40, 60, 100, 160, 240, 400 and 580 in that order; they are not fitted curves. All 36 points are retained, including non-monotonic throughput and coincident recalls. Each configuration was measured once; uncertainty and statistical significance were not estimated. Memory admission uses whole-process peak RSS and zero sampled swap, not a cgroup hard limit. Source Data are supplied alongside the figure.
