# logs/ 的用途

`logs/` 保存终端输出、报错、进程号和队列状态，不是源码。2026-09-18 检查时约 728 KiB。

| 位置 | 内容 | 处理建议 |
|---|---|---|
| `memory_environment/` | 旧内存 01/02/03 实验和诊断日志，约 168 KiB | 不再追溯旧实验时可归档删除 |
| `disk_environment/` | 磁盘 01/02/03 和维护日志，约 328 KiB | 保留需要复现/排错的运行记录 |
| `05_core_graphs/` | Ours、共享图、系统建图和队列日志，约 60 KiB | 建图追溯与统计可能依赖，不按旧编号删除 |
| `uci_sift10m/` | 下载、转换、ground truth、候选生成与建图日志，约 136 KiB | 保留数据来源与准备记录 |
| `msmarco_graph_build_20260915/` | 建图日志、manifest 和状态，约 16 KiB | 同建图证据处理 |
| 根目录 `*.log`、`*.pid`、状态文件 | 一次性运行输出与进程/队列状态 | 先确认不再被运行任务或恢复脚本使用 |

新实验的正式原始日志与参数/指标一起保存在 `results/disk/runs/<run-id>/.../artifacts/` 等目录。根 `logs/` 主要服务于运维和历史脚本，不应从任意日志中摘取性能数字当作通过验收的论文数据。

论文源码提交包通常排除运行生成的 `logs/`；保留必要证据应随对应结果批次提交。此次只说明用途，没有清空日志、修改数据或迁移历史结果。
