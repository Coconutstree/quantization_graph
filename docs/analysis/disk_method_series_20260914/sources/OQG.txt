Hardware-Optimized Quantized Graphs for Fast Similarity Search
Anonymous Author(s)
Abstract
Similarity search is a fundamental primitive in modern data systems,
where approximate nearest neighbor search (ANNS) enables high re-
call with low query latency. Quantized graph (QG) methods achieve
state-of-the-art ANNS performance by combining graph traversal
with distance evaluation over compact vector codes. However, ex-
isting designs are limited by (i) inefficient distance evaluation stem-
ming from high-precision lookup tables that restrict register-level
parallelism; (ii) hardware-constrained quantization that prevents
flexible bit allocation and high-precision distance computation; and
(iii) traversal strategies that underutilize hardware parallelism or
rely on redundant connectivity, leading to high memory overhead.
We presentOptimized Quantized Graph(OQG), a novel hardware-
optimized QG method that achieves high-performance approximate
similarity search through the co-design of flexible quantization, effi-
cient and accurate distance evaluation, and a traversal strategy that
exposes parallelism without increasing memory footprint. OQG
decouples lookup precision from accumulation precision using
compact low-bit lookup tables with high-precision register-level
accumulation, preserving distance accuracy during traversal. OQG
further enables flexible bit allocation through a novel multi-register
design for high-bit quantized codes and introduces a new multi-
path traversal strategy that aggregates candidates into large eval-
uation batches without increasing graph connectivity or memory
overhead. We conduct the largest experimental evaluation of QG
methods to date across 30 diverse datasets and show that OQG con-
sistently outperforms the strongest existing methods in accuracy,
throughput, and memory efficiency, with comparable indexing per-
formance. At high recall (Recall@100≈ 0.98), OQG achieves up to
5x higher throughput compared to SymQG while reducing memory
up to 1.8x. We release the OQG library as open source to ensure
reproducibility, enable further research, and ease integration.
1 Introduction
Similarity search plays a central role in contemporary data infras-
tructures [2, 3, 56, 111, 135], enabling efficient retrieval over large
vector collections for tasks such as retrieval-augmented genera-
tion [46, 77, 79] and machine learning [19, 26, 115, 121, 138, 142, 143].
Exact nearest neighbor searchguarantees retrieval of the true near-
est neighbors but incurs prohibitive computational cost at scale,
especially for high-dimensional data.Approximate nearest neigh-
bor search (ANNS)addresses this challenge by efficiently retrieving
near-matching vectors without guaranteeing the exact nearest ones,
achieving recall close to exact search with much lower latency.

ANNS methods include graph [ 41, 89], quantization [ 48, 65],
hashing [49, 60, 96], and tree [1, 42] methods. Among them, graph-
based methods achieve state-of-the-art performance in recent bench-
marks and studies [10, 31, 70, 80]. Graph methods construct a prox-
imity graph that connects each vector to a small set of nearby
neighbors and perform search via greedy, distance-guided traversal
starting from an entry point. By exploiting local connectivity and
short paths in the graph, graph methods efficiently narrow the
search space and achieve high recall with low query latency.
Although graph methods are highly effective, distance computa-
tion on high-dimensional raw vectors remains expensive and often
dominates query latency during traversal [148]. To reduce this cost,
quantized graph (QG)methods [4, 53, 63, 117, 148] combine graph
search with vector quantization, replacing exact distance compu-
tation with fast approximate evaluation on compact codes. Among
quantization techniques,Product Quantization (PQ)is particularly
attractive because PQ splits vectors into subspaces and represents
each subspace by a learned centroid index, achieving high com-
pression ratio and approximation accuracy [ 148]. Recent meth-
ods [6–8, 16] further accelerate PQ-based distance evaluation by
exploiting CPU vectorization for parallel table lookup and distance
accumulation, substantially reducing memory traffic and improving
throughput. To further improve search throughput, some QG meth-
ods [63] build on these hardware-efficient PQ kernels and adopt a
redundancy connectivitythat stores neighbor codes alongside each
node, enabling distance evaluation over an entire neighborhood
via a single contiguous memory access during graph traversal.
Despite recent progress, three key properties remain critical
for improving the performance of QG methods. Designs based
onScalar Quantization (SQ)[ 4, 117, 148] rely on a single shared
codebook across all dimensions, limiting their ability to capture het-
erogeneous structures in high-dimensional data. While PQ-based
approaches improve representational fidelity, existing hardware-
accelerated designs [7, 8, 16, 62] restrict PQ to low bitwidths (e.g., 4
bits per subspace) to fit lookup tables into vector registers, allowing

saturation is a pervasive issue. However, achieving high-precision
accumulation efficiently remains challenging. RaBitQ-based meth-
ods (e.g., SymQG) [45, 53] adopt QuickerADC-style [7, 8] distance
evaluation but retain low-precision accumulation throughout tra-
versal, limiting effective resolution. While extensions of Quicker-

low-precision accumulation or incur high-cost lookup operations to
maintain precision, lacking an efficient mechanism to achieve high-
precision distance computation without increasing lookup cost.
Second, flexible quantization granularity remains limited, yet is
essential for adapting to diverse dataset characteristics and accuracy
targets. Existing QG methods [53, 117] adopt fixed per-dimension
bitwidths (e.g., 8-bit in SQ or 1-bit in RaBitQ), restricting their
ability to adjust encoding precision to different data distributions.
While extensions such as Ex-RaBitQ [43] support multiple bits per
dimension, combining them with QG significantly increases mem-
ory usage due to the need to store higher-precision codes for all
graph nodes, making such designs impractical at scale. As shown
in Figure 1(c), different datasets favor different bits per dimension
to achieve the best accuracy–throughput trade-off. Fixed-bitwidth
designs cannot capture such variations, leading to suboptimal per-
formance across diverse datasets. Finally, memory-efficient hard-
ware acceleration remains a key challenge for vector search. In
practice, graph expansions often expose only a limited number
of neighbors (e.g., 16), making it difficult to form large candidate
batches and leaving hardware parallelism underutilized [53]. How-
ever, efficient execution requires processing larger batches (e.g., 32
or 64 candidates) to achieve high throughput. SymQG addresses
this by introducing redundant connectivity to increase per-step
candidate counts, but this comes at the cost of substantial memory
overhead. Consequently, current approaches fail to effectively bal-
ance throughput and memory efficiency. In addition to the above
methodological limitations, prior works evaluate performance only
on a limited number of datasets and lack statistical validation of
their findings, hindering generalization across diverse datasets.
To address the aforementioned limitations, we proposeOpti-
mized Quantized Graph(OQG), a hardware-accelerated QG method
that jointly improves distance evaluation efficiency, quantization
flexibility, and traversal-level hardware utilization. First, OQG in-
troduces a novel distance evaluation pipeline that decouples lookup
precision from accumulation precision. By employing compact low-
bit lookup tables, OQG maximizes the number of distance values
processed per register, while widening and accumulating distances
in high precision only at the register level, preserving numerical res-
olution during traversal while significantly increasing evaluation
throughput. Second, OQG extends this pipeline to support flexi-
ble bit allocation by orchestrating multiple registers to represent
and process high-bit quantized codes, removing register-aligned
bitwidth constraints and enabling accurate distance accumulation
under heterogeneous quantization settings. Finally, OQG intro-
duces a new traversal strategy that explores multiple search paths
in parallel and aggregates their candidates into large evaluation
batches, improving hardware utilization without increasing graph
connectivity. In contrast to approaches that rely on expanded or
redundant neighborhoods to expose parallelism, this design pre-
serves sparse graph structure while maintaining high throughput
and low memory overhead. Table 1 summarizes these properties
and shows that OQG is the first QG method to simultaneously
achieve flexible quantization, high-precision distance evaluation,
and memory-efficient hardware-aware traversal.
To evaluate the effectiveness of OQG, we conduct the largest
study of QG methods to date, spanning 30 diverse datasets and
employing rigorous statistical analysis. Across all settings, OQG
consistently dominates the accuracy–throughput–memory trade-
off compared to the strongest high-performance QG methods [4, 53,
62, 117, 148]. Figure 1(a) shows that for high recall (e.g., Recall@100
≈ 0.98), OQG achieves up to 6.4x and 5.0x higher throughput than
Glass and SymQG, respectively, while reducing memory usage by
up to 1.8x (Figure 1(b)). Experiments on 100-million-scale datasets
further corroborate these findings, demonstrating that OQG main-
tains its accuracy and throughput advantages at scale while reduc-
ing memory usage by up to 32% and indexing time by up to 8.6x. We
release the OQG library as open source to ensure reproducibility
and enable integration into existing vector search systems [9].
We first review the relevant background and preliminaries in
Section 2. We then summarize our contributions as follows:
• Flexible bit allocation via multi-register.We orchestrate mul-
tiple registers to support high-bit codes, removing register-aligned
bitwidth constraints to enable flexible bit allocation (Section 3.1).
• Low-bit lookup with high-precision accumulation.We de-
sign a vectorized PQ lookup kernel that uses low-bit lookup tables
with high-precision distance accumulation to enable efficient and
accurate distance evaluation (Section 3.2).
• Cross-batch candidates aggregation.We aggregate candidate
nodes from multiple search paths to form large batches for par-
allel distance evaluation without increasing graph connectivity,
thereby reducing memory overhead (Section 3.3).
• Comprehensive evaluation.We evaluate OQG and the strongest
QG baselines on 30 diverse datasets and two large-scale datasets,
with rigorous statistical analysis, showing consistent improve-
ments in throughput, accuracy, and memory (Sections 4 and 5).
We discuss related work at Section 6 and conclude at Section 7.

2 Background and Preliminaries
This section presents the relevant preliminaries and related meth-
ods. We first introduce PQ for efficient ANNS (Section 2.1), then
summarize graph-based ANNS methods and their traversal strate-
gies (Section 2.2), and finally review quantized graph methods
that integrate vector quantization into graph search (Section 2.3).
Together, these methods outline the algorithmic foundations for
searching billions of vectors within a second.

2.2 Accelerating ANNS with Graph Structures
Graph-based ANNS indices link each vector to a small set of neigh-
bors and perform greedy, distance-guided traversal. NSW [17, 72]
is an early design that achieves strong accuracy by enriching local
links with a few long-range connections, enabling search to quickly
jump toward promising regions. However, its single-layer struc-
ture can require many greedy steps on large datasets. HNSW [89]
addresses this by building a hierarchy of layers: upper layers use
sparse long-range links for coarse navigation, while lower layers
provide dense local refinement. Three parameters govern its behav-
ior:𝑅, the maximum number of neighbors per node;EFConstruction,
the candidate list size used during insertion; andEFSearch, the num-
ber of candidate nodes retained during querying. Increasing any
of these parameters gives the algorithm access to more candidate
neighbors, which improves the chances of finding closer nodes and
thus increases accuracy. However, doing so also raises construction
cost or query latency because more distance evaluations and more
bookkeeping must be performed. This hierarchical design underlies
many state-of-the-art ANNS methods [53, 117].
Building on the same greedy, distance-guided traversal principle,
NSG [41] constructs a sparse graph with neighbors that are both
close in distance and well distributed in direction. This design pre-
serves connectivity and enables effective navigation during search.
Its performance is primarily controlled by the maximum node de-
gree and the search candidate size: increasing these parameters im-
proves recall by exposing more candidate neighbors, but increases
memory usage and query cost due to additional distance evaluations.
These graph structures form the foundation for efficient quantized
graph designs, which we introduce next to further reduce distance
computation cost while preserving strong search performance.

2.3 Quantized Graphs: Enabling Billion-Scale
Search within a Second
Quantization has emerged as a powerful technique for accelerating
graph-based ANNS by reducing the cost of distance approximation
during neighbor expansions, enabling search over billions of vec-
tors within a second [10, 70]. Instead of computing distances in full
precision, graph search can operate on compact codes produced by
scalar quantization (SQ)[ 149], achieving substantially lower compu-
tation and memory traffic. SQ maps each dimension to a few discrete
levels, and integrating it into graph structures has been shown to
be highly effective; for example, Glass [117] incorporates SQ into
graph traversal and achieves state-of-the-art throughput in pub-
lic benchmarks [10, 70]. VSAG [148] further accelerates search by
dynamically tuning memory prefetch parameters to reduce latency.
Beyond SQ-based designs, several methods incorporate more
expressive quantization into graph traversal. OG-LVQ [4] extends
Vamana [64] by replacing floating-point vectors withlocal vec-
tor quantization (LVQ)codes, reducing both memory and distance
computation cost. NGT-QG [63] applies PQ within the ONNG struc-
ture to accelerate traversal, while SymQG [53] replaces PQ with
RabitQ [45], an error-bounded quantizer that improves quantiza-
tion accuracy while maintaining efficient distance computation.
As illustrated in Figure 2, to further reduce traversal overhead,
these methods commonly adopt aredundancy structure—storing
quantized representations of all neighbors directly within each
node—which enables contiguous memory access and efficient batch
distance evaluation at the cost of additional memory.
Although these methods enable fast and accurate graph search
and show strong results on certain benchmarks, their performance
is not consistently robust across diverse datasets and often incurs
substantial memory overhead. This motivated OQG, which achieves
strong and stable performance across 30 diverse datasets while
reducing memory overhead, as we demonstrate later (Section 5.1.1).
3 Optimized Quantized Graph
We present the core design of OQG, focusing on hardware-conscious
distance evaluation and traversal in quantized graphs. We first intro-
duce a novel flexible 8-bit PQ-based distance approximation pipeline
that enables fully register-resident SIMD lookups (Section 3.1). We
then extend this design with 16-bit distance accumulation to pre-
serve distance resolution and support accurate graph navigation
(Section 3.2). Finally, we propose a new connectivity augmentation,
which aligns graph traversal with wide-vector SIMD execution by
exposing sufficiently large neighbor batches per expansion step
(Section 3.3). These components enable high-throughput, accurate
navigation, and a low memory footprint in OQG.
3.1 Flexible PQ-based Distance Approximation
This subsection begins by motivating the need for flexible quantiza-
tion, and then presents our SIMD-efficient PQ distance evaluation
design, featuring a novel multi-register organization that enables
efficient high-bit lookup with flexible bit allocation, and lays the
foundation for high-precision distance accumulation.
Motivation.Existing QG methods such as NGT-QG rely on fixed
4-bit sub-quantizers, limitingeach subspaceto 16 centroids and
introducing substantial distance distortion [ 8], a limitation that
cannot be resolved by simply increasing the total bit budget. Unlike
SQ and RaBitQ, which rely on fixed bitwidthper dimension, OQG
enables flexible bit allocation to accommodate heterogeneous quan-
tization requirements, achieving better throughput–accuracy trade-
offs across datasets, as illustrated later (e.g., Figure 9). To realize this
flexibility, OQG leverages 8-bit codes—the minimum addressable
storage unit on modern CPUs—as a building block, while its novel
multi-register design allows large LUTs and multiple subspace-
specific LUTs to be held simultaneously in SIMD registers. This
removes the register-aligned bitwidth constraint in prior SIMD-
based methods and enables flexible, higher-bit quantization with-
out sacrificing SIMD efficiency. Although QuickerADC supports
8-bit quantization, its implementation is typically constrained to
fixed subspace configurations (e.g., 8 or 16) [8] and lacks a founda-
tion for efficiently supporting high-precision distance accumulation,
which we address in Section 3.2. In contrast, our design enables true
flexible subspace configurations while achieving up to 1.75x faster
kernel-level distance evaluation under the same subspaces (Table 3).

3.3 Cross-Batch Candidates Aggregation
As discussed in Section 3.2, our PQ kernel can evaluate a batch of 64
approximate distances in parallel using SIMD instructions. To fully
utilize this capability, prior QG methods such as SymQG [53] expose
a large number of candidate neighbors per expansion step by relying
on a single node. Specifically, they increase the effective graph de-
gree to match the SIMD width (e.g., 32/64 neighbors) and materialize
the quantized representations of all neighbors in a contiguous mem-
ory layout. As illustrated in Figure 7(a), this design enables a single
SIMD computation over a large batch of neighbors from one node.
Motivation.While effective for hardware utilization, this design
tightly couples the SIMD batch size with graph connectivity. Achiev-
ing full SIMD utilization requires increasing the node degree to𝐵,
which introduces significant redundancy in memory. Concretely,
each node must store the quantized codes of all𝐵 neighbors, result-
ing in a memory overhead of𝐵𝑁 (e.g.,64𝑁 ). Moreover, enforcing
high-degree connectivity alters the graph structure, increasing con-
struction complexity and potentially introducing redundant local
neighbors that contribute limited new information during search.
This design, therefore, trades memory efficiency and structural spar-
sity for SIMD utilization, making it less suitable for large-scale or
memory-constrained settings. This limitation motivates our novel
design that decouples SIMD utilization from graph connectivity.

size from the per-node graph degree by advancing multiple search
paths in parallel and aggregating candidates across them. Instead
of requiring a single node to expose𝐵 neighbors, we maintain mul-
tiple active nodes from different paths, each contributing a small

effective aggregation, we must identify multiple entry points that
are both close to the query and sufficiently diverse. Selecting entry
points from the top layer (𝐿max) yields candidates that are too far
from the query, while selecting from the bottom layer (𝐿0) leads
to highly redundant candidates due to dense local connectivity.
We therefore select entry points from an intermediate layer (e.g.,
𝐿1), which provides a natural balance between proximity and di-
versity. Nodes at this level are already close to the query due to
hierarchical traversal, while still maintaining structural diversity
across the graph. We select the top-𝑘 candidates from this layer and
propagate them to the bottom layer, where their neighborhoods
are aggregated for SIMD evaluation.
By combining multi-entry selection with cross-batch candidates
aggregation, the resulting SIMD batches cover diverse regions of
the search space while remaining focused around the query. In this
sense, multi-entry selection determineswhichnodes contribute to
each batch, while cross-batch candidates aggregation determines
howtheir distances are evaluated efficiently with reduced memory.

Statistical Analysis.We employ a ranking-based statistical eval-
uation to compare accuracy across all datasets. For each dataset,
methods are ranked according to Recall@100, and their average
rank summarizes overall accuracy performance. Statistical signif-
icance is assessed at the 95% confidence level using the Friedman
test [39], followed by the Nemenyi test [92] to determine whether
rank differences exceed a critical threshold. Results are summarized
using aCritical Difference (CD)diagram, which places methods
along a horizontal axis according to their average ranks; methods
connected by a horizontal bar do not differ significantly, whereas the
absence of a connection indicates a statistically significant accuracy
difference. To complement this global analysis, we reportpairwise
recall comparison plotsthat compare methods on each dataset. For
each pairwise comparison, we apply the Wilcoxon signed-rank
test [125] and report the corresponding p-value (𝑝𝑤), which indi-
cates whether the observed recall differences across datasets are
statistically significant. At the 95% confidence level, a difference is
considered statistically significant when𝑝 𝑤≤0.05.
Evaluated Methods and Parameter Settings.We compare our
method against six high-performance ANNS libraries, including
five that support quantized graph search—SymQG [53], Glass (Zil-
liz) [117], NGT (Yahoo Japan) [62], OG-LVQ (Intel) [4], and VSAG
(Ant Group) [148]—as well as the vanilla HNSWlib [89]. Because
different quantized graph methods expose different quantization
parameters, we adopt aparameter searchstrategy to ensure a fair
comparison. For each method and dataset, parameter search enu-
merates all supported quantization configurations and selects the
one that achieves the highest throughput while maintaining a recall
of at least 0.95. If a method cannot reach 0.95 recall on a dataset,
we instead use a recall threshold of 0.9. For all baselines except
NGT, we fixEFConstructionto 600 and vary 𝑅∈{ 32, 64}, following
prior work [53] (see Section 2.2 for details). NGT exposes a large
number of training parameters; therefore, we follow the default
settings recommended in its official library. During evaluation, we
vary the search-time parameters to obtain accuracy–throughput
trade-off curves. We apply thisparameter searchstrategy as follows:
(i) OQG builds on product quantization and requires selecting the
number of subspaces; we perform a grid search over the number
of subspaces to identify the optimal setting. For OQG , we fixEF-
Constructionto 600 and vary 𝑅∈{ 8, 16}. Unlike prior quantized
graph methods such as SymQG, which require the graph degree to
be a multiple of the SIMD batch size (e.g., 32) to fully utilize vector
lanes, OQG does not impose such constraints. This flexibility is
enabled by our cross-batch aggregation design, which decouples
graph connectivity from SIMD execution while maintaining high
hardware efficiency. (ii) SymQG integrates RabitQ [45] with graph
search. RabitQ quantizes each dimension to a single bit, eliminating
the need for parameter tuning. We do not consider the graph-based
Ex-RabitQ [43], as its support for multi-bit quantization per dimen-
sion leads to proportional memory overhead, which is impractical
at scale, and it currently lacks an official implementation. (iii) Glass
supports scalar quantization using either 8-bit unsigned integers or
8-bit floating-point values; we evaluate both options and select the
better-performing configuration for each dataset. We adopt NSG as
the base graph, since it consistently achieves better search perfor-
mance in terms of throughput and accuracy than HNSW within the
Glass library in our experiments. (iv) OG-LVQ combines LVQ [4]
with the VAMANA graph [64] and provides multiple quantization
variants, including LVQ8x8, LVQ4x8, and LVQ8. We evaluate all
supported variants, as well as the unquantized setting, and select the
best configuration per dataset. (v) NGT provides graph structures
such as ONNG together with PQ-based quantization but exposes a
large number of quantization parameters. In our parameter search,
we evaluate both the quantized configuration (following the official
recommendations for 4-bit PQ per subspace) and the unquantized
configuration, and select the better-performing setting for each
dataset. We include the unquantized option because NGT only sup-
ports 4-bit PQ, which can substantially reduce accuracy on some
datasets. (vi) VSAG supports scalar quantization with 16-bit or 8-bit
precision; we evaluate both quantization precisions and select the
optimal setting for each dataset.

5.2.1 16-bit Distance Accumulation for Accurate Navigation.As dis-
cussed in Section 3.2, 8-bit accumulation severely limits the dynamic
range of PQ distance aggregation across subspaces, causing distance
saturation and degraded neighbor ordering during graph traversal.
Our analysis over 30 diverse datasets shows that traversal distances
commonly exceed the 8-bit range but fit within 16-bit precision,
motivating 16-bit accumulation for reliable navigation.
Navigation Distance and Scale Analysis.We mimic a single
navigation step as follows. Given a query vector𝑞 and a graph node
𝑣 with neighbor setN(𝑣) (with|N(𝑣)|= 64), we compute distances
{𝑑(𝑞,𝑢)|𝑢∈N(𝑣)}. We then record thetop-5 distance, defined
as the 5-th smallest value,𝑑(5)(𝑞,𝑣) . For each dataset, we average
𝑑(5)(𝑞,𝑣) over all visited nodes𝑣 and all queries𝑞, yielding a single
representative navigation distance per dataset. Figure 15(a) plots
the distribution of these per-dataset Top-5 distances across all 30
datasets (log scale). The dashed vertical lines indicate the maximum
representable values under8-bit(255) and16-bit(65,535) distance
accumulation. As shown in Figure 15(a), the per-dataset Top-5 navi-
gation distances consistently fall above the 8-bit accumulation limit
(255) and below the 16-bit limit (65,535) across all 30 datasets. This
means 8-bit accumulation saturates during navigation, collapsing
meaningful distance differences among neighbors and degrading
traversal decisions, whereas 16-bit accumulation preserves the re-
quired dynamic range and enables reliable graph navigation.

5.3 Understanding OQG across top-𝑘Regimes
The top-𝑘 parameter affects both the search workload and the
impact of distance computation and traversal optimizations in
graph-based ANNS. Smaller 𝑘 values favor low-latency naviga-
tion with limited candidate expansion, whereas larger 𝑘 values
require evaluating more candidates and incur heavier distance com-
putation. To study this effect, we evaluate OQG across different
top-𝑘 regimes and compare it against the two strongest baselines,
SymQG and Glass. Figures 16(c)–(f) show throughput–recall curves
on GLOVE and GIST for𝑘∈{ 20, 100}. OQG consistently outper-
forms both baselines, achieving up to 3.8x (GLOVE) and 1.7x (GIST)
speedups at𝑘= 20, and substantially larger gains of 10.8x and 3.0x
at𝑘= 100. These results indicate that OQG benefits increasingly in
computation-intensive regimes, where its SIMD-optimized distance
evaluation amortizes overhead over a larger number of candidates.
To analyze cost composition across different𝑘 values, Figures 16(a)
and (b) report latency breakdowns with EFSearch=𝑘 . At small
𝑘= 20, LUT construction accounts for a large portion of total la-
tency (48% on GLOVE and 57% on GIST). As𝑘 increases, this fixed
overhead is amortized: at𝑘= 100, LUT construction contributes
only 24% of total latency on GLOVE and 37% on GIST. Consequently,
performance at larger𝑘 is dominated by SIMD-efficient distance
computation rather than setup costs, explaining the substantially
larger speedups observed in high-𝑘 regimes. Overall, OQG deliv-
ers consistent gains across all top-𝑘 settings, with its advantages
becoming most pronounced as computation intensity increases.
6 Related Work
This section complements the background in Section 2 and positions
our approach within the broader ANNS literature.
Graph methods for ANNS [4, 23, 24, 32, 33, 40, 41, 53, 62–64, 67,
69, 88, 89, 99, 110, 117, 128, 129, 133, 134, 136, 140, 148] organize
vectors into proximity graphs that enable efficient neighbor-based
traversal during search. In parallel, quantization techniques [ 4,
11, 12, 38, 43, 45, 48, 52, 54, 57, 65, 78, 84, 90, 94, 106, 114, 120,
144, 149] compress high-dimensional vectors into compact discrete
codes, enabling fast approximate distance evaluation with reduced
memory footprint. More recent studies bridge these two direc-
tions by integrating quantization compression directly into graph
nodes [4, 33, 53, 62, 117, 148], formingquantized graphindices that
accelerating distance computation during graph traversal. Beyond
graph and quantization approaches, ANNS has also been studied
through hashing and tree paradigms. Hash methods [49, 58, 60, 76,
86, 105, 108, 124, 124, 146, 147] project high-dimensional vectors
into lower-dimensional representations using multiple hash func-
tions, such that nearby points are likely to share the same hash
codes; query processing retrieves candidates from matching hash
buckets and refines results via exact distance computation. Tree
methods [1, 15, 18, 21, 42, 91, 118] partition the data space into hi-
erarchical regions, with each leaf node containing a disjoint subset
of points. During search, the query traverses the tree from the root
by selecting child nodes that are closest to the query, and candidate
points stored in the reached leaves are then exhaustively evaluated.
Many tree methods rely on hyperplane partitioning [1, 20, 22, 29, 34,
73, 83, 97, 98, 101, 104, 113, 116, 119, 131, 150], which uses randomly
oriented or axis-aligned hyperplanes to construct balanced trees and
guide queries toward regions likely to contain nearest neighbors.
Beyond indexing techniques, filtered ANNS [28] incorporates
attribute-based constraints into similarity search. Equality-based
methods [50, 81, 95, 112, 127, 137] target discrete attributes by
maintaining separate indices or inverted structures for each filter
value, whereas range-filter methods [36, 66, 82, 99, 130, 141] han-
dle continuous attributes through multi-dimensional partitioning,
quantization, and metadata-aware pruning. In parallel, substantial
effort has focused on accelerating ANNS across hardware plat-
forms. On CPUs, prior work reduces computation via progressive
distance estimation [30, 44, 75, 132], or accelerates low-bit distance
accumulation using vectorized operations [6–8, 16, 74]. GPU-based
methods [27, 47, 55, 69, 71, 107, 128, 145] leverage massive paral-
lelism to speed up both traversal and distance computation, while
FPGA designs [5, 67, 68, 103, 139] emphasize pipelined execution
and on-chip data reuse to improve energy efficiency. Moreover, sev-
eral methods [37, 51, 109] extend existing ANNS indices to support
streaming, cloud-based, and federated search services.
7 Conclusion
We presented OQG, a hardware-accelerated QG method that ad-
dresses key limitations in existing QG search systems. By jointly
enabling flexible quantization, high-precision distance accumula-
tion, and cross-batch candidates aggregation, OQG improves ac-
curacy, throughput, and memory across a wide range of operating
regimes. Extensive experiments on 30 diverse datasets, including
two large-scale datasets, demonstrate that OQG consistently out-
performs state-of-the-art quantized graph baselines under both
accuracy-critical and throughput-oriented settings. These results
show that careful co-design of quantization, distance computation,
and graph traversal is essential for high-performance ANNS.
