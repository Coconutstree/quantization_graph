# OG-LVQ 磁盘适配逐步拆解：逐向量标量量化、Vamana 与按页取码

第一部分按 SAQ 解读的顺序介绍论文原方法：全流程与符号 → 分步训练/编码 → 索引存储与查询 → 误差与边界。第二部分简述我们的磁盘实验改动和实际执行顺序。2026-09-15 调整结构；实验实现以此前核对的代码快照为依据，本次不运行新实验。

## 第一部分：论文中的 LVQ 方法

### 一、先看全流程与符号

LVQ 的全称是 Locally-adaptive Vector Quantization：先对数据库中心化，再对每个向量独立选择标量量化范围；第一层压缩码支撑图构建与遍历，可选第二层残差码用于最终重排。这里 local 指逐向量范围，不是局部 PQ 码本。依据的是 Similarity search in the blink of an eye with compressed indices。

| 符号 | 类型 / 含义 |
| --- | --- |
| x,q,c∈Rᴰ | 数据库向量、浮点 query、数据库均值 |
| rₓ=x−c；aₓ,bₓ | 中心化向量；该向量坐标的最小值和最大值 |
| B₁,Δₓ,kₓ | 一级 bit 数、步长、整数标签向量 |
| r̃ₓ,eₓ,êₓ；B₂ | 一级重建、其残差、残差重建；二级 bit 数 |
| R,W,kout | 图出度、候选池宽度、最终返回数 |

![论文方法：LVQ 一级编码与可选残差重排](figures/04_og_lvq_flow.png)

### 二、步骤 1：减均值，使各维偏移更一致

$$
c=\frac1N\sum_xx,\qquad r_x=x-c,\qquad r_q=q-c.
$$

输入是数据库向量，输出是共享均值与中心化向量。减均值本身保持两点 L2，不损失信息；它降低各维固定偏移对范围的影响，让后面的逐向量标量量化更有效利用可用数值区间。LVQ 不需要 PCA 旋转、维度分段或 PQ 的多套 k-means 子码本。

### 三、步骤 2：为每个向量选择范围并编码

$$
a_x=\min_j r_{x,j},\quad b_x=\max_j r_{x,j},\quad\Delta_x=\frac{b_x-a_x}{2^{B_1}-1}.
$$

$$
k_{x,j}=\operatorname{clip}\!\left(\operatorname{round}\frac{r_{x,j}-a_x}{\Delta_x},0,2^{B_1}-1\right),\quad\widetilde r_{x,j}=a_x+\Delta_xk_{x,j}.
$$

以上写法适用于非零范围；常量向量需用退化分支处理。输出是 B₁-bit 标签和两个范围常数（也可以等价表示成尺度与偏移）。不同向量独立使用整个整数区间，避免共享全局范围被少数大值支配。原论文通常以低精度保存范围常数，并可按缓存行粒度补齐。

教学例子：B₁=4、范围 [−1,2] 时，步长为 0.2；坐标 0.34 编码为 7、重建为 0.4。若另一个向量范围缩为 [−0.1,0.2]，步长变为 0.02。自适应来自每个向量的尺度，不来自标签位宽变化。

### 四、步骤 3：可选地编码一级重建残差

$$
e_x=r_x-\widetilde r_x,\qquad\widetilde x^{(1)}=c+\widetilde r_x,\qquad\widetilde x^{(2)}=c+\widetilde r_x+\widehat e_x.
$$

理想最近舍入时，一级残差每坐标位于约 [−Δₓ/2,Δₓ/2]。论文用 B₂ bit 在这个由一级步长确定的范围内再做标量量化，因此第二级不必另存一套逐向量范围常数。这里讲的是编码范围；不能由此断言真实量化误差在所有数据上严格均匀或独立。

输出是一对码，记为 LVQ-B₁×B₂。遍历时只读一级；候选确定后才取得二级码并提升距离精度。总码量增加约 DB₂ bit，另计一级常数和对齐；这不会变成“免费”的精度补偿。

### 五、步骤 4：压缩向量怎样参与图构建

论文采用 Vamana 式图：以每个点为 query 搜索邻居候选，排序并剪枝，加入反向边且限制出度。可以用 LVQ 压缩表示完成这些距离计算，以降低构建时的向量内存与访存量。论文分析了量化误差对图剪枝等步骤的影响，并用实验验证低比特构图的实用性。

构图中的两端都来自数据库，而在线 query 可以保持浮点，因此距离计算端点不同。压缩构图有效的证据并不等于任何 bit 数、任何分布下都生成完全相同的图。

### 六、步骤 5：索引存储与在线距离

| 对象 | 论文中的用途 |
| --- | --- |
| 共享均值 | 编码与查询使用相同中心 |
| 一级标签及范围常数 | 支撑建图和图遍历 |
| 可选二级残差标签 | 仅对最终候选精细重排 |
| 邻接表与入口 | 决定搜索路径 |
| 候选池/访问标记 | query 工作区 |

$$
\widehat d_1^2(q,x)=\sum_j\left[(q_j-c_j)-(a_x+\Delta_xk_{x,j})\right]^2.
$$

query 保持浮点；码可在距离内核中按需解码，不必预先解压全库。分数是到重建向量的 L2；它没有 SAQ 式“保存真实模长、只修正交叉项”的比值结构。原论文还用向量化与数据排列改善解码和内存访问。

### 七、步骤 6：图遍历与双层重排

从入口开始，以一级近似距离维护最多 W 个候选，每次展开最近的未处理节点并评估邻居，直到没有待展开候选。单层版本直接根据一级分数返回。双层版本取回最终候选的残差码，以两层重建重新排序：

$$
\widehat d_2^2(q,x)=\|q-(c+\widetilde r_x+\widehat e_x)\|^2.
$$

二级码改善的是候选集合内的距离，不会重新搜索已经因一级分数和有限池而遗漏的区域。W 是搜索宽度，也不是两级 bit 数或图出度。

### 八、从误差看方法边界

$$
\epsilon_x=\widetilde x-x,\qquad\widehat d^2-d^2=-2(q-x)^\top\epsilon_x+\|\epsilon_x\|^2.
$$

逐向量范围更充分地利用 bit，但单向量中的极端坐标仍能拉大步长。加入二级后，误差中的 ε 换成两层重建误差；重建更准一般有利于排序，却不保证有限图搜索的 recall 单调提高。还需考虑低精度范围常数带来的附加误差。

原论文 §2—5：[Similarity search in the blink of an eye with compressed indices](https://www.vldb.org/pvldb/vol16/p3433-aguerrebere.pdf)

## 第二部分：我们的磁盘实验改了什么

项目名 OG-LVQ 对应 SVS Vamana + 单层 LVQ4，不启用论文的二级残差重排。官方 SVS 建图/保存的图行和码行转换成 graph.pages、lvq4.pages，按 4 KiB 打包；中心常驻，图和码按需读取并共享 query 内页缓存。

![我们的磁盘实验：存储边界与读取顺序](figures/04_og_lvq_storage.png)

实际顺序：读取入口 LVQ 行 → 一级评分入池 → 选 u 并读取图行 → 对新邻居逐个读取 LVQ 行、评分入池 → 按 LVQ4 分数返回 top-10。磁盘行保留 Turbo 排列，末尾有两个 float32 的 scale/bias 和一个中心 selector。

查询端采用兼容 SVS 保存布局的本地解码距离和搜索循环；它并非直接调用原封不动的官方 SIMD kernel。内存/磁盘 top-10 parity 脚本用于检验行为一致性；本次不重新运行。

实现定位：experiments/05_disk_system_fair/native/og_lvq_disk_port.cpp；tests/run_og_lvq_disk_port_parity.py。用户提供的 LVQ.pdf 实为 LOPQ，本篇依据上列正确 LVQ 论文。
